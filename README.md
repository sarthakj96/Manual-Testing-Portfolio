# Portfolio: End-to-End Functional Testing (E-Commerce/Food Delivery)

## Project Context
After stepping away from my previous role to focus on upskilling, I built this repository to keep my core QA competencies sharp and production-ready. Instead of relying on old enterprise artifacts, I chose to reverse-engineer and test high-traffic, real-world user workflows on modern consumer applications. 

This repository serves as live proof of my current test design capabilities, structural thinking, and attention to detail.

## Core QA Stack
* **Test Engineering:** Functional Testing, Boundary Value Analysis, Equivalence Partitioning, Negative Testing
* **Documentation:** Test Case Suites, Bug Logging, Traceability Logic
* **Tools Used:** MS Excel / Google Sheets, Azure DevOps (Defect Tracking Concepts)

## Repository Deliverables
* **`ECommerce_Checkout_TestCases.xlsx`** 
  A comprehensive, execution-ready test suite targeting critical payment thresholds, coupon validation, and checkout flows.
* **`Sample_Defect_Logs.pdf`** 
  Realistically documented bug reports featuring precise steps to reproduce, severity assessments, and expected vs. actual results.
